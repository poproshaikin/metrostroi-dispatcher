# Metrostroi Dispatcher

Диспетчер-бот (ДЦХ) для Metrostroi: смены, график, приказы, разбор смены. Работает в синглплеере и на сервере, только Lua, только серверная часть.

> Статус: этап 1 в работе. Готов слой `Line` (модель линии); график, смена и разбор — дальше.

## Структура

```
lua/autorun/server/dispatcher_init.lua   точка входа, грузит модули после Initialize
lua/dispatcher/line.lua                  Line: фасад над API Метростроя (станции, составы, позиция)
lua/dispatcher/debug.lua                 отладочные команды
lua/dispatcher/maps/<map>.lua            опциональный конфиг карты (поправки названий и т.п.)
```

Планируется: `schedule.lua` (график), `shift.lua` (смена, state machine), `report.lua` (метрики и разбор), `comms.lua` (сообщения `[ДЦХ]`, команды `!понял`), `orders.lua` (приказы).

## Разработка

Клонировать в `garrysmod/addons/` (или сделать туда junction/symlink). GMod сам перезагружает изменённые Lua-файлы прямо в игре.

Отладка:

| Команда | |
|---|---|
| `dispatcher_stations` | станции и платформы, как их видит `Line` (вывод в консоль) |
| `dispatcher_where` | состояние твоего состава |
| `dispatcher_debug 1` | состояние на экране раз в 0.5 с + прибытие/отправление в чат |
| `lua_run PrintTable(Dispatcher.Line.GetPlayerState(Entity(1)))` | сырой стейт |

## Line API

Модули выше `Line` не трогают Метрострой напрямую — только это API. Расстояния в метрах вдоль пути, скорость в км/ч.

```lua
Line.GetStations()          -- { Station, ... } по порядку линии
Line.GetStation(id)         -- Station
Line.NextPlatform(platform) -- следующая платформа по ходу (тот же индекс пути), nil на конечной
Line.OrderDir(index)        -- +1 / -1: куда по списку станций идёт путь index

Line.GetConsists()          -- { Consist, ... }  (состав = электрически сцепленные вагоны)
Line.GetPlayerConsist(ply)  -- Consist | nil
Line.GetState(consist)      -- State | nil
Line.GetPlayerState(ply)    -- State | nil
```

```lua
Station  = { id = 101, name = "Некрасовка", order = 1, platforms = { [1] = Platform, [2] = Platform } }
Platform = { station, index, xStart, xEnd, length, terminal, ent }   -- xEnd = знак остановки

State = {
    consist, head, driver,   -- головной вагон и машинист (Player | nil)
    wagons     = 5,
    speed      = 54.2,  stopped = false,
    doors      = { left = false, right = true },
    onTrack    = true,       -- false: вне путевой сети
    at         = Platform,   -- платформа, вдоль которой сейчас голова состава
    stop       = Platform,   -- ближайший знак остановки впереди (может быть = at)
    distToStop = 312.5,      -- метры до знака; nil, если неизвестно (другой участок пути)
    last       = Platform,   -- где последний раз останавливался
}
```

События (только для составов с машинистом):

```lua
hook.Add("Dispatcher_Arrive", "my", function(consist, state, platform, stopError) end)
-- stopError: метры до знака остановки при остановке (+ недоезд, - переезд), nil если неизвестно
hook.Add("Dispatcher_Depart", "my", function(consist, state, platform) end)
```

## Schedule (график)

`lua/dispatcher/schedule.lua`. Время — то же, что на станционных часах (`Line.Now()`).

- **Время хода**: оценка Метростроя (`Metrostroi.GetTravelTime`: 82% от ограничения АРС + 25 с), если не считается — по расстоянию при 45 км/ч. При `dispatcher_learn 1` уточняется по твоим реальным перегонам и сохраняется в `data/dispatcher/runs_<карта>.json`.
- **Рейс**: от платформы до конечной, стоянка `dispatcher_dwell` (30 с), оборот на конечной `dispatcher_turnover` (240 с). Смена — цепочка рейсов туда-обратно.
- **Слежение**: план/факт прибытия и отправления, ошибка остановки у знака, проследование без остановки, слишком короткая стоянка (< 15 с), раннее отправление. Допуск `dispatcher_tolerance` (15 с).

```lua
S.BuildTrip(fromPlatform, depTime, toPlatform?) -> Trip
S.BuildRoute(fromPlatform, depTime, count)      -> { Trip, ... }
S.Assign(consist, trips) / S.Cancel(consist) / S.GetAssignment(consist) / S.CurrentTrip(consist)
S.GetStatus(consist) -> { trip, stop, plannedArr, eta, deviation }
-- для приказов:
S.SkipStop(trip, platform)  S.Hold(trip, platform, sec)  S.Shift(trip, sec)  S.TurnBack(assignment, platform)
```

События: `Dispatcher_StopArrive/StopDepart (cid, trip, stop, deviation)`, `Dispatcher_StopMissed (cid, trip, stop)`, `Dispatcher_TripDone (cid, trip)`, `Dispatcher_ShiftDone (cid, assignment)`.

Команды: `dispatcher_trip [N]` (N рейсов от текущей платформы, по умолчанию 2), `dispatcher_schedule`, `dispatcher_trip_cancel`, `dispatcher_runs`, `dispatcher_runs_reset`.

Сообщения `[ДЦХ]` в чат — `lua/dispatcher/comms.lua`.

## Orders (приказы)

`lua/dispatcher/orders.lua`. Один активный приказ на поезд; каждый сразу меняет график.

| Приказ | Чат | Выполнен | Нарушен |
|---|---|---|---|
| **Оборот** — рейс заканчивается на промежуточной станции со съездом/тупиком | `!оборот [ст.]` | прибыл на противоположную платформу | прибыл на станцию дальше по старому направлению |
| **Проследовать без остановки** | `!проследовать [ст.]` | прибыл на следующую станцию, не останавливаясь | остановился на этой станции |
| **Задержка отправления** | `!задержка [сек] [ст.]` | отправился не раньше нового времени | отправился раньше или проехал станцию |
| **Ограничение скорости** на перегоне до станции | `!ограничение [км/ч] [ст.]` | ехал не быстрее лимита (+2 км/ч, не дольше 2 с) | превышение; ДЦХ предупреждает сразу |

- `!приказ` — случайный приказ прямо сейчас; без станции — ближайшая подходящая.
- Случайно: с вероятностью `dispatcher_orders_chance` в минуту (0.08), не больше `dispatcher_orders_per_trip` (2) за рейс и не раньше чем через 90 с после предыдущего, только на ходу и не позже чем за 600 м до станции.
- Подтверждение: `!понял`; без подтверждения приказ повторяется через 60 с.
- Оборотные станции карты — `turnbacks` в `lua/dispatcher/maps/<map>.lua`.

События: `Dispatcher_OrderIssued / OrderDone / OrderViolated (order)`.

## Тупики (sidings)

Оборотный тупик можно разметить как остановку: заехать в тупик, встать у знака/упора, написать `!тупик [название]` (суперадмин). Тупик привязывается к последней проеханной платформе (например, Нижегородская, путь I) и сохраняется в `data/dispatcher/sidings_<карта>.json`; можно также перечислить в `sidings` конфига карты.

Если у платформы прибытия есть тупик, оборот в графике планируется по шагам: высадка на платформе (`dispatcher_unload`, 60 с) → прибытие в тупик → смена кабины (`dispatcher_cabchange`, 120 с) → отправление из тупика → противоположная платформа. Без тупика — одним куском `dispatcher_turnover`. Работает и для приказа на оборот, если у оборотной станции размечен тупик.

Команды: `!тупик [название]`, `!тупики`, `!тупик_удалить <название>`.

## Депо

`lua/dispatcher/depot.lua`. Пути депо обычно не входят в путевую схему Метростроя (на Некрасовке — нет), поэтому путь депо (канава) — отрезок в мире между двумя маркерами: **начало** и **конец**.

- Разметка (суперадмин): встать торцом кабины у начала канавы — `!канава 3 начало`, доехать до конца — `!канава 3 конец`.
- Поезд **на канаве** — оба конца состава между маркерами (±5 м вдоль, до ~1.5 м от оси). **Отъезд** — тронулся и хоть один конец вышел за маркеры.
- `!рейс [N]`, стоя целиком на канаве: наряд на N **кругов** (по умолчанию 1; круг — до дальней конечной и обратно к станции заезда. Некрасовка: 1 = Лух → Нижегородская → Лух, 2 = ещё и через Некрасовку). Выход из депо (`dispatcher_depot_prep`, 7 мин на приёмку; приняли раньше — `!готов`, отправление через минуту) → станция выезда → рейсы → станция заезда → постановка на свободный путь депо. Встал не на тот путь — ДЦХ скажет.
- Станция выезда/заезда запоминается сама при первом выезде/заезде, или `!выезд <станция> [путь]`, `!заезд <станция> [путь]`. Время перегона депо ↔ линия — `dispatcher_depot_run` (300 с), дальше учится.
- `!канавы` — список путей, `!канава_удалить 3`.

## Метки в мире

`!метки` — показать/скрыть столбики с подписями: начало (зелёный) и конец (красный) канав, тупики (оранжевый), знаки остановки платформ (синий). Удобно проверять разметку и калибровку.

## Где хранятся данные

Всё, что размечено или выучено в игре, лежит на сервере в `garrysmod/data/dispatcher/`, JSON, по файлу на карту:

| Файл | Что |
|---|---|
| `sidings_<карта>.json` | тупики |
| `stopmarks_<карта>.json` | калибровка знаков остановки |
| `depot_<карта>.json` | пути депо, станции выезда/заезда |
| `runs_<карта>.json` | выученное время перегонов |

**Перенос на другой сервер**: скопировать эти файлы в `garrysmod/data/dispatcher/` там (карта должна быть той же версии). Или `!экспорт` — вся разметка карты одним Lua-конфигом в `data/dispatcher/export_<карта>.txt`; сохранить его как `lua/dispatcher/maps/<карта>.lua` в аддоне — и разметка будет работать везде, где стоит аддон. Сохранённое в `data/` имеет приоритет над конфигом карты.

## Карты

Работает на любой карте, где у платформ (`gmod_track_platform`) есть путевая сеть Метростроя. Названия станций берутся из `Metrostroi.StationConfigurations` карты, поправить можно в `lua/dispatcher/maps/<map>.lua`. Проверяется на `gm_metro_nekrasovskaya_line_v6`.
